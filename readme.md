# WML — определение параметров Windows, macOS и Linux

## О проекте

`WML` — консольная программа на Python, являющаяся частью лабораторной
работы по дисциплине **«Технологии программирования»**.

Название `WML` связано с поддерживаемыми платформами:

- **W** — Windows;
- **M** — macOS;
- **L** — Linux.

Программа предназначена для определения операционной системы и сохранения
основных характеристик компьютера в JSON-файл. Она демонстрирует
использование кроссплатформенных модулей стандартной библиотеки Python и не
требует сторонних пакетов.

## Назначение

Программа нужна для получения и сохранения краткой информации о текущей
системе:

- какая операционная система запущена;
- какой выпуск и версия ядра системы используются;
- как называется компьютер в сети;
- какая архитектура процессора установлена;
- сколько доступно логических ядер;
- сколько всего оперативной памяти;
- сколько всего и свободно места на диске;
- какая версия и реализация Python используются;
- когда были собраны сведения.

`WML` работает в режиме чтения системных сведений и сохраняет результат в
файл `system_configuration.json`. Настройки операционной системы,
пользовательские файлы и оборудование не изменяются.

## Используемые модули

Программа использует только стандартную библиотеку Python:

- `platform` — определение операционной системы и получение сведений о
  платформе и Python;
- `os` — получение количества логических ядер процессора;
- `shutil` — получение информации о дисковом пространстве;
- `pathlib.Path` — определение корня текущей файловой системы;
- `datetime` — фиксация даты и времени сбора сведений;
- `json` — сохранение конфигурации в JSON-файл.

Размеры памяти и дискового пространства переводятся из байтов в гигабайты
по формуле `байты / 1024³` и округляются до двух знаков после запятой.

## Требования

- Windows, macOS или Linux;
- Python версии **3.10 или новее**;
- права на чтение сведений о текущей файловой системе.

Установка дополнительных зависимостей не требуется.

## Запуск

Перейдите в каталог `WML` из терминала.

### Windows PowerShell

```powershell
cd WML
py main.py
```

Если команда `py` недоступна, используйте:

```powershell
python main.py
```

### macOS и Linux

```bash
cd WML
python3 main.py
```

Также можно запустить программу из среды разработки, например PyCharm,
выбрав файл `main.py` и конфигурацию запуска Python. После запуска в текущем
каталоге создаётся или перезаписывается файл `system_configuration.json`.

## Принцип работы

1. `platform.python_version()` и `platform.python_implementation()` возвращают
   версию и реализацию Python.
2. `platform.uname()` возвращает имя системы, имя компьютера, выпуск и версию
   ядра, а также архитектуру.
3. `os.cpu_count()` определяет количество логических ядер.
4. `Path.cwd().anchor` получает корень файловой системы текущего рабочего
   каталога.
5. `shutil.disk_usage()` возвращает общий и свободный объём диска.
6. На macOS и Linux `os.sysconf()` получает общий объём оперативной памяти.
7. Функция `bytes_to_gb()` переводит значения памяти и диска из байтов в
   гигабайты.
8. `datetime.now().astimezone()` фиксирует локальные дату и время сбора.
9. Все сведения объединяются в словарь и сохраняются в
   `system_configuration.json` с отступами.

## Пример результата

Конкретные значения зависят от компьютера и времени запуска программы.

```text
{
    "python": {
        "version": "3.14.7",
        "implementation": "CPython"
    },
    "system": {
        "name": "Darwin",
        "hostname": "MacBook-Air.local",
        "kernel_release": "27.0.0",
        "kernel_version": "Darwin Kernel Version 27.0.0",
        "architecture": "arm64"
    },
    "processor": {
        "logical_cores": 10
    },
    "disk": {
        "total_gb": 228.27,
        "free_gb": 51.14
    },
    "memory": {
        "total_gb": 16.0
    },
    "collection": {
        "date": "2026-10-01",
        "time": "14:26:58",
        "datetime": "2026-10-01T14:26:58+03:00"
    }
}
```

Порядок ключей и форматирование соответствуют файлу, создаваемому
программой. Версия системы, имя компьютера, архитектура, количество ядер,
объём памяти и диска, а также время сбора будут соответствовать фактической
системе пользователя.

## Результат лабораторной работы

Результатом выполнения `WML` является файл `system_configuration.json` с
информацией о текущей операционной системе и базовой конфигурации компьютера.

В ходе работы демонстрируется создание переносимой программы, которая
использует единый программный интерфейс Python для доступа к системным
данным, преобразует полученные значения и сохраняет их в структурированном
формате JSON.

## Ограничения

- Программа получает только сведения, доступные стандартной библиотеке и
  текущему пользователю.
- Данные о диске относятся к файловой системе, определённой текущим рабочим
  каталогом, а не обязательно ко всем подключённым накопителям.
- Точное название модели компьютера и процессора не определяется.
- В текущей версии сбор общего объёма памяти реализован для macOS и Linux.
  Функция для Windows пока не реализована, поэтому на Windows программа не
  сможет корректно завершить сбор памяти.
