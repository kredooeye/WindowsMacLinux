# WML — определение параметров Windows, macOS и Linux

## О проекте

`WML` — консольная программа на Python, являющаяся частью лабораторной
работы по дисциплине **«Технологии программирования»**.

Название `WML` связано с поддерживаемыми платформами:

- **W** — Windows;
- **M** — macOS;
- **L** — Linux.

Программа предназначена для определения операционной системы и вывода
основных характеристик компьютера. Она демонстрирует использование
кроссплатформенных модулей стандартной библиотеки Python и не требует
сторонних пакетов.

## Назначение

Программа нужна для получения краткой информации о текущей системе:

- какая операционная система запущена;
- какая версия системы используется;
- как называется компьютер в сети;
- какая архитектура процессора установлена;
- сколько доступно логических ядер;
- сколько места занимает, используется и свободно на диске.

`WML` работает в режиме чтения: программа только получает системные сведения
и выводит их в терминал. Настройки операционной системы, пользовательские
файлы и оборудование не изменяются.

## Используемые модули

Программа использует только стандартную библиотеку Python:

- `platform` — определение операционной системы и получение сведений о
  платформе;
- `os` — получение количества логических ядер процессора;
- `shutil` — получение информации о дисковом пространстве;
- `pathlib.Path` — определение корня текущей файловой системы.

Размеры дискового пространства переводятся из байтов в гигабайты по формуле
`байты / 1024³` и округляются до двух знаков после запятой.

## Требования

- Windows, macOS или Linux;
- Python версии **3.10 или новее**;
- права на чтение сведений о текущей файловой системе.

Установка дополнительных зависимостей не требуется.

## Запуск

Перейдите в каталог `WML` из терминала.

### Windows PowerShell

```powershell
cd WML
py main.py
```

Если команда `py` недоступна, используйте:

```powershell
python main.py
```

### macOS и Linux

```bash
cd WML
python3 main.py
```

Также можно запустить программу из среды разработки, например PyCharm,
выбрав файл `main.py` и конфигурацию запуска Python.

## Принцип работы

1. С помощью `platform.system()` определяется текущая операционная система.
2. В консоль выводится сообщение о найденной платформе.
3. `platform.uname()` возвращает версию системы, имя компьютера и архитектуру.
4. `os.cpu_count()` определяет количество логических ядер.
5. `Path.cwd().anchor` получает корень файловой системы текущего рабочего
   каталога.
6. `shutil.disk_usage()` возвращает общий, занятый и свободный объём диска.
7. Функция `bytes_to_gb()` переводит значения из байтов в гигабайты.
8. Все сведения выводятся в терминал.

Программа не сохраняет результат в JSON-файл: итогом работы является
консольный отчёт.

## Пример результата

Конкретные значения зависят от компьютера, на котором выполняется программа.

```text
Программа запущена на Windows
Version: 10.0.26100
Hostname: STUDENT-PC
Architecture: AMD64
Logical cores: 12
Total disk space: 476.94 GB
Used disk space: 214.38 GB
Free disk space: 262.56 GB
```

На macOS первая строка будет иметь вид:

```text
Программа запущена на macOS
```

На Linux:

```text
Программа запущена на Linux
```

Версия операционной системы, имя компьютера, архитектура, количество ядер и
объём диска будут соответствовать фактической системе пользователя.

## Результат лабораторной работы

Результатом выполнения `WML` является информация о текущей операционной
системе и базовой конфигурации компьютера, представленная в терминале.

В ходе работы демонстрируется создание переносимой программы, которая
одинаково запускается на Windows, macOS и Linux и использует единый
программный интерфейс Python для доступа к системным данным.

## Ограничения

- Программа выводит только сведения, доступные стандартной библиотеке и
  текущему пользователю.
- Данные о диске относятся к файловой системе, определённой текущим рабочим
  каталогом, а не обязательно ко всем подключённым накопителям.
- Точное название модели компьютера и процессора не определяется.
- Результат не записывается в отдельный файл и доступен только в консоли.
